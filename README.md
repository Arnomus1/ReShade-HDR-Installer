# ReShade HDR Installer

**ReShade HDR Installer** injects ReShade 6.8 with an HDR path on DX11, DX12 and Vulkan. RenoDX tonemap, LUT, dlss 5 reshade after the overlay.

## How to use
1. Download v6.8.0.
2. Extract `ReShade-HDR-Installer.zip`.
3. Point it at the game exe.
4. Apply. Launch. Enable HDR in the overlay.

## FAQ

**Black screen?**
Disable the HDR preset, then add RenoDX after the overlay.

**Which API?**
The installer reads the exe. Notes in `files/lut/`.

## Requirements
Windows 10/11. DirectX or Vulkan game.
